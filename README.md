# Sistema de Inventario con Python y Flet

Aplicación de inventarios desarrollada en Python utilizando el framework Flet.
Permite administrar, visualizar datos en tablas, eliminar, buscar productos
y guardar los datos en archivo JSON para persistencia.

## Características principales
- Interfaz gráfica moderna con Flet.
- Registro y edición de datos.
- Validación de entradas (ej: nombres de productos sin números).
- Tabla interactiva con colores personalizables.
- Persistencia de datos en archivos JSON.
- Arquitectura modular y escalable.

## Requisitos
- Python 3.10+
- Flet (instalable desde pip)

## Instalación
```bash
git clone https://github.com/Catpower118/sistema-de-inventarios.git
cd sistema-de-inventarios
pip install -r requirements.txt
```

## Ejecución
```bash
python main.py
```
